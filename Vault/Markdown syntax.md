Markdown is a lightweight markup language used to format plain text so that it can be easily converted into HTML. It relies on simple symbols like ==hashes, asterisks, and brackets== to structure documents. [1, 2, 3]

## Basic Formatting

- Headers: Add 1 to 6 `#` symbols before your text. More hashes make smaller headers.
    
    ```markdown
    # Heading 1
    ## Heading 2
    ### Heading 3
    ```
    
- Bold: Wrap text in double asterisks or double underscores.
    
    ```markdown
    **Bold Text** or __Bold Text__
    ```
    
- Italics: Wrap text in single asterisks or single underscores.
    
    ```markdown
    *Italic Text* or _Italic Text_
    ```
    
- Strikethrough: Wrap text in double tildes.
    
    ```markdown
    ~~Strikethrough Text~~
    ```
    
    [3, 4, 5, 6]

## Lists and Quotes

- Unordered Lists: Begin lines with a hyphen, asterisk, or plus sign, followed by a space.
    
    ```markdown
    - Item A
    * Item B
    + Item C
    ```
    
- Ordered Lists: Begin lines with numbers followed by a period and a space.
    
    ```markdown
    1. First item
    2. Second item
    ```
    
- Blockquotes: Add a `>` symbol before the text.
    
    ```markdown
    > This is a quoted sentence.
    ```
    
    [2, 4, 7]

## Links, Images, and Code

- Hyperlinks: Place the clickable text in brackets and the URL in parentheses.
    
    ```markdown
    [Visit Google](https://google.com)
    ```
    
- Images: Use the link format but add an exclamation mark at the very front.
    
    ```markdown
    ![Alt Text](image-url.jpg)
    ```
    
- Inline Code: Wrap text in single backticks.
    
    ```markdown
    Use `code` here.
    ```
    
- Code Blocks: Wrap multiple lines in triple backticks.

### Extended Elements

* **Horizontal Rule**: Place three or more hyphens, asterisks, or underscores on a line by themselves.
```markdown
---
````

- Tables: Use vertical bars to separate columns and hyphens to create header rows.
    
    ```markdown
    
    | Header 1 | Header 2 |
    | -------- | -------- |
    | Cell 1   | Cell 2   |
    ```
    
    [8, 10, 11, 12]
