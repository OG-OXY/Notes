*** Set Up
:PROPERTIES:
:CUSTOM_ID: set-up
:END:
To replicate that exact terminal-native =zk= + Helix markdown notebook
workflow from the video on your NixOS system, you only need a very lean
stack.

Here are the packages required:

*** 1. The Core CLI & Search Engines
:PROPERTIES:
:CUSTOM_ID: the-core-cli-search-engines
:END:
- *=zk=* --- The plaintext note-taking assistant and LSP server
  (=pkgs.zk=). This is the engine that handles indexing, templates,
  frontmatter generation, and the Language Server Protocol.
- *=ripgrep=* (=pkgs.ripgrep= or =pkgs.rg=) --- Required under the hood
  by =zk= for lightning-fast text searching across your notes.
- *=fzf=* (=pkgs.fzf=) --- Used by =zk= for interactive terminal pickers
  (=zk list -i=, =zk edit -i=).

*** 2. The Text Editor & LSP Client
:PROPERTIES:
:CUSTOM_ID: the-text-editor-lsp-client
:END:
- *=helix=* (=pkgs.helix= or =pkgs.hx=) --- Your modal editor, which
  will automatically talk to the =zk= language server for diagnostics,
  code actions (=space a=), go-to-definition (=gd=), and hover docs
  (=space k=).

| ​### How to Add Them to Your NixOS Config                                                                                                      |
| If you manage your packages declaratively (e.g., in your system configuration or home-manager configuration), you can drop them in like this: |
| ```nix environment.systemPackages = [ pkgs.zk pkgs.ripgrep pkgs.fzf pkgs.helix];                                                              |
| ```                                                                                                                                           |

*** Quick 3-Step Setup to Get It Running
:PROPERTIES:
:CUSTOM_ID: quick-3-step-setup-to-get-it-running
:END:
1. *Initialize a notebook directory:*

#+begin_src sh
mkdir -p ~/Notes/zk-vault
cd ~/Notes/zk-vault
zk init
#+end_src

/(It will ask you a couple of quick preferences, like whether you want
to use WikiLinks---say yes!)/ 2. *Configure Helix to hook =zk= into
Markdown:* Inside your notebook folder, =zk= can manage a
=.helix/languages.toml= file, or you can add it to your global
=~/.config/helix/languages.toml= so it fires up whenever you open a
=.md= file inside your notes directory:

#+begin_src toml
[[language]]
name = "markdown"
language-servers = [ "zk" ]

[language-server.zk]
command = "zk"
args = ["lsp"]
#+end_src

3. [@3] *Start writing notes:*

- Run =zk new "My First Note"= from your shell, or use
  =zk edit --interactive= to fuzzy-find and open notes instantly.

-
