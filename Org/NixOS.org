Your command is almost perfect, but because you are running nixos-install from a live, booted system rather than the minimal installer ISO environment, you just need to adjust the flag order slightly so it targets your mount point properly.

The Exact Command for Your System Root

From your repository root, run the installation targeting your extra drive's mount point (assuming it's mounted at /mnt):

fish

sudo nixos-install --flake .#nixos --root /mnt

The Fast Re-Cloning Phase

** Once you boot into that clean extra drive, you can wipe your main SSD and drop the pristine image right back onto it using a fast, block-level clone:

1. Verify your drive letters using lsblk so you don't overwrite the wrong disk.

2. Clone the pristine system back to your main SSD:fish

#+BEGIN_SRC shell
sudo dd if=/dev/sdX of=/dev/sdY bs=4M status=progress conv=fsync
#+END_SRC

(Where sdX is your extra drive and sdY is your primary SSD).
This completely bypasses the need for an installer USB while ensuring your final primary system state has absolutely zero historical baggage.
