** Syntax Rules
- All `;` variations are syntactically identical (line comments).
- Helix defaults to `;` (`comment-token = ";"`) as the minimal comment character.

** Hierarchy & Auto-Indentation
- `;` :: Inline margin notes (auto-aligned to col 40 by Emacs).
- `;;` :: Standard line notes/code blocks (indents to current code depth).
- `;;;` :: File headers (`;;; config.el -*- ... -*-`) & main outline sections.
- `;;;;` :: Major structural banners in massive packages.
