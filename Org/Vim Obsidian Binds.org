In Vim modal mode (which Obsidian's engine uses), there is *no default
=<Leader>= key* assigned until you explicitly define one!

By default, Vim only knows standard modal keys (like =i= for insert,
=hjkl= for movement, =:= for commands). To make =Space= act as your
Leader key, you have to unmap standard =Space= first and tell Vim to
treat =Space= as =<Leader>=.

Here is the exact setup to put in your =.obsidian.vimrc= file inside
your vault root (=~/Notes/Obsidian/.obsidian.vimrc=):

| ​### =.obsidian.vimrc= Config                                                                                                       |
| ```vim ” 1. Unmap default Space behavior and set Space as Leader unmap let mapleader=” ”                                           |
| ” 2. Example: Space + w to Save exmap save obcommand workspace:save-buffer nmap w :save                                            |
| ” 3. Example: Space + f to open Quick Switcher (Helix style) exmap quickSwitcher obcommand switcher:open nmap f :quickSwitcher ``` |

*** Why You Need =exmap= in Obsidian
:PROPERTIES:
:CUSTOM_ID: why-you-need-exmap-in-obsidian
:END:
Unlike standard Neovim/Vim, Obsidian's internal commands (like opening
the Quick Switcher or saving) aren't native Vim functions. The *Vimrc
Support* plugin uses =exmap= to bridge Obsidian actions to Vim
keybindings:

1. =exmap customName obcommand <obsidian-command-id>=
2. =nmap <Leader>f :customName=

| ​### How to Find Any Obsidian Command ID                                                                                                                                                                                       |
| If you want to bind other Helix habits (like toggling file tree, splits, or global search):                                                                                                                                   |
| 1. Open Obsidian *Settings -> Vimrc Support*. 2. Look at the command inspector or run =M-x= / =Ctrl+P= in Obsidian to see command names. 3. Use =exmap <alias> obcommand <id>= in your =.obsidian.vimrc= and reload Obsidian! |
