Markdown is a lightweight markup language used to format plain text so
that it can be easily converted into HTML. It relies on simple symbols
like ==hashes, asterisks, and brackets== to structure documents. [1, 2,
3]

** Basic Formatting
:PROPERTIES:
:CUSTOM_ID: basic-formatting
:END:
- Headers: Add 1 to 6 =#= symbols before your text. More hashes make
  smaller headers.

  #+begin_src markdown
  # Heading 1
  ## Heading 2
  ### Heading 3
  #+end_src

- Bold: Wrap text in double asterisks or double underscores.

  #+begin_src markdown
  ,**Bold Text** or __Bold Text__
  #+end_src

- Italics: Wrap text in single asterisks or single underscores.

  #+begin_src markdown
  ,*Italic Text* or _Italic Text_
  #+end_src

- Strikethrough: Wrap text in double tildes.

  #+begin_src markdown
  ~~Strikethrough Text~~
  #+end_src

  [3, 4, 5, 6]

** Lists and Quotes
:PROPERTIES:
:CUSTOM_ID: lists-and-quotes
:END:
- Unordered Lists: Begin lines with a hyphen, asterisk, or plus sign,
  followed by a space.

  #+begin_src markdown
  - Item A
  ,* Item B
  + Item C
  #+end_src

- Ordered Lists: Begin lines with numbers followed by a period and a
  space.

  #+begin_src markdown
  1. First item
  2. Second item
  #+end_src

- Blockquotes: Add a =>= symbol before the text.

  #+begin_src markdown
  > This is a quoted sentence.
  #+end_src

  [2, 4, 7]

** Links, Images, and Code
:PROPERTIES:
:CUSTOM_ID: links-images-and-code
:END:
- Hyperlinks: Place the clickable text in brackets and the URL in
  parentheses.

  #+begin_src markdown
  [Visit Google](https://google.com)
  #+end_src

- Images: Use the link format but add an exclamation mark at the very
  front.

  #+begin_src markdown
  ![Alt Text](image-url.jpg)
  #+end_src

- Inline Code: Wrap text in single backticks.

  #+begin_src markdown
  Use `code` here.
  #+end_src

- Code Blocks: Wrap multiple lines in triple backticks.

  [2, 3, 4, 8, 9]

=python print("Hello World")=

#+begin_src unset
