** 2. The Pure Rust + Nix Development Pattern
:PROPERTIES:
:CUSTOM_ID: the-pure-rust-nix-development-pattern
:END:
Since you use devenv or pure devShells inside your Flakes, never install
rustc or cargo globally in your environment.systemPackages. Instead,
lean into your custom-wired architecture. Drop a minimal flake.nix into
your Rust project directory that spins up an exact, reproducible Rust
toolchain using the Rust Overlay or standard pkgs.mkShell:

* Example of the lean, explicit style you prefer
:PROPERTIES:
:CUSTOM_ID: example-of-the-lean-explicit-style-you-prefer

{ inputs = { nixpkgs.url = "github:nixos/nixpkgs/nixos-unstable"; };

outputs = { self, nixpkgs }: let system = "x_86_64-linux"; # adjust to
your system pkgs = nixpkgs.legacyPackages.\({system};
  in {
    devShells.\){system}.default = pkgs.mkShell { buildInputs = [
pkgs.rustc pkgs.cargo pkgs.rust-analyzer pkgs.clippy ]; }; }; }
